This project name is GIT LOG 
By taking help of this application user can set their workout routine according to required time and calorie burn.
This project build on Next.js library. JavaScript used as programming language and jsx used as rendering scripted language. Also for show toast here used toastify npm package.
Five key Features of this project are 
1. user can make today's workout list
2. user can make later day's workout list
3. user can delete exercise from list
4. user can see description for each workout
5. user can show total workout time , burned calories for each day's exercises list.
